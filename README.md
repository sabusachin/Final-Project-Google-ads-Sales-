# Google Ads Sales Data Analytics Project

## Project Overview
This project focuses on analyzing Google Ads sales data using Python to understand campaign performance and identify useful business insights.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn


## Project Tasks
- Inspected and cleaned the raw dataset.
- Handled missing values and inconsistent data.
- Performed data preprocessing and exploratory data analysis (EDA).
- Analyzed clicks, impressions, leads, conversions, advertising costs, and sales revenue.
- Compared campaign performance across devices and locations.
- Identified potential outliers using the IQR method.


## Objective
The main objective is to understand advertising campaign performance, identify trends, and use data-driven insights to evaluate marketing effectiveness.
